# Shahn Masr — Game Top-Up Website (Draft v1)

> **Status: Early draft.** This is the first implemented milestone — the **homepage only** — built for review before the rest of the site (FAQ page and beyond) is implemented. Expect content, copy and visuals to change.

Shahn Masr is a game top-up storefront for the Egyptian market: players buy in-game currency and gift cards (PUBG Mobile UC, Free Fire Diamonds, Fortnite V-Bucks, PlayStation/Xbox/Steam credit, etc.) and pay locally via **Vodafone Cash** or **PayPal**, without needing an international Visa card.

## Tech stack

No frontend framework — this is deliberately plain, static output:

| Layer | Choice |
|---|---|
| Markup | Static HTML, generated by a small Node build script |
| Styling | [Tailwind CSS v4](https://tailwindcss.com/) (CLI build, no CDN) |
| Interactivity | Vanilla JavaScript (no dependencies) — mobile nav toggle, game category tabs |
| Build tooling | Node.js (`type: module`, ES imports) — used only at build time, not shipped to the browser |

The build script (`scripts/build.js`) imports content from `src/data/*.js` and composable section templates from `src/sections/*.js`, and writes plain `.html` files to `dist/`. `dist/` is fully static — it can be hosted anywhere (Netlify, GitHub Pages, S3, cPanel, etc.) with zero server-side runtime required.

## Project structure

```
shahn-masr-web/
  scripts/
    build.js          Assembles dist/*.html from data + section templates
    copy-assets.js     Copies static assets into dist/
    serve.js            Minimal static file server for local preview
  src/
    layout.js           Shared <html>/<head> shell
    pages/
      home.js            Composes the homepage from sections, in order
    sections/            One file per homepage section (pure render functions)
    data/                All editable content — text and image URLs, imported by sections
    css/
      input.css           Tailwind entry point + design tokens (@theme)
    js/
      main.js              Client-side interactivity, copied into dist/ as-is
  dist/                  Build output (generated, not hand-edited)
```

Content and presentation are intentionally separated: every game, offer, testimonial, FAQ entry and stat lives in `src/data/`, and each homepage section imports only the data it needs. Adding or editing a game, price, or testimonial never requires touching a section or layout file.

## Getting started

Requires Node.js 18+.

```bash
npm install         # install Tailwind CSS
npm run build        # build HTML + CSS + copy assets into dist/
npm run serve         # serve dist/ locally at http://localhost:4173
```

During active CSS work, run the Tailwind watcher alongside the static server:

```bash
npm run watch:css
```

## Scripts

| Command | What it does |
|---|---|
| `npm run build` | Full build: HTML → Tailwind CSS → asset copy |
| `npm run build:html` | Regenerate `dist/*.html` from `src/pages` + `src/sections` + `src/data` |
| `npm run build:css` | Compile `src/css/input.css` → `dist/css/style.css` |
| `npm run watch:css` | Rebuild CSS on change |
| `npm run copy:assets` | Copy static assets (JS, images) into `dist/` |
| `npm run serve` | Serve `dist/` locally |
